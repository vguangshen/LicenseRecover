# LicenseRecover v1.0.0

This is the first versioned stable baseline after the safety, UI, project-layout and release-pipeline refactors.

## Highlights

- Modern Swing GUI is now the default user interface, with the legacy GUI retained as a fallback.
- Java / .NET application detection is centralized, including automatic DS01xx legacy-protocol selection.
- Default high-risk write paths create and verify prewrite / prepatch backups before modifying files.
- Backup verification uses both file length and SHA-256 content validation.
- Batch detection uses typed targets and no longer crosses unrelated child-directory boundaries into a parent application.
- Source layout is standardized under `src/main/java` and `src/test/java` while preserving Java 8 and default-package compatibility.
- Local builds and GitHub Actions share the same `scripts/verify.ps1` pipeline.
- The runtime overlay is deterministic and validated in CI.
- Generated all-in-one ZIP files are distributed through GitHub Releases instead of being tracked in the repository root.

## Compatibility

- Java 8 compatibility baseline retained.
- Windows 7 / Windows Server 2008 GUI compatibility remains supported as a project constraint.
- Existing runtime JARs, .NET helper binaries and legacy BAT launchers remain available.

## Assets

- `LicenseRecover-latest.zip`
- `SHA256SUMS.txt`

Use `run_gui.bat` for the recommended modern GUI. Use the `*_legacy.bat` launchers only when compatibility fallback is needed.
