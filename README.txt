LicenseRecover v1.2.57
=====================

ITMC 云实训平台离线授权恢复工具（Java / .NET）。
便携版内置 Amazon Corretto Java 8，支持既有 Windows 兼容范围。

快速启动
--------
1. 从 GitHub Releases 下载 LicenseRecover-latest.zip。
2. 解压后双击 LicenseRecoverGUI.exe（无需另装 Java）。
3. 单应用：选择目录、检测、执行支持的一键恢复。
4. 批量应用：先扫描、确认目标与预览结果，再执行。
5. 危险操作、备份删除均需额外确认；只支持已识别的应用。

v1.2.57 变更
------------
- 更新安装采用文件级事务式回滚；覆盖失败会恢复旧文件并删除本轮新建文件。
- 合并单应用与一键恢复的目录检测、日志记录、过期入口清理逻辑。
- 移除废弃 GUI 注入层、过时迁移脚本和无效占位方法。
- 主界面保留单应用、批量应用及高级兼容选项。
- 已有注册码手动导入模块已移除；不影响受支持目标的原生写入流程。
- .NET DS01xx 旧协议仍不支持一键自动写回，不应将阻断联网当作授权成功。

历史变更请查阅 CHANGELOG.md；本版详情见 RELEASE_NOTES.md。
