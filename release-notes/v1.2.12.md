# LicenseRecover v1.2.12

本版修复 DS2406 实机验证暴露出的旧版 `ITMCReg` 构造器兼容问题。

- DS2406 的 `ITMCReg-1.0.2.jar` 只有 `RegisterMain(String product, String configPath)` 两参数构造器。
- v1.2.11 的兼容 fallback 错把 `jsonForMain` 作为第二参数，导致 `checkReInfo()` 从错误路径读取配置；本地授权即使已按 `DS24` 写入，也会继续跌落到 HASP 检查并报 `NoClassDefFoundError: Aladdin/Hasp`。
- v1.2.12 改为反射识别构造器：3 参数版本传 `(product, json, configPath)`；2 参数版本传 `(product, configPath)`。
- DS2406 的授权模型仍保持 `SoftVersionID=DS2406 / ProName=DS24 / RegStr=DS2406`。
- 保留原生校验失败自动回滚。
