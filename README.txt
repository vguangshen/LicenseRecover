LicenseRecover v1.2.68
=====================

ITMC 离线授权恢复工具（Java / .NET），包含 Windows 便携启动程序。

启动：解压 LicenseRecover-latest.zip 后运行 LicenseRecoverGUI.exe。

v1.2.68 只读扫描更新
------------------
- 批量扫描与被动预览只读取静态证据，不通过 Java 注册探针执行目标代码。
- 显示组件哈希/元数据、检测方法、原生验证安全审计结论与无法验证的原因。
- 111 个主类及内部类自动收录，并对最终完整 ZIP 和轻量更新 ZIP 做运行时验证。
- 26 个真实应用的独立扫描输入副本均可识别，授权仍显示灰色“未验证”；这不代表未激活。
- 真实原版/Patch 双指纹库仍为空，原生授权有效/无效尚不能确认。

本地测试：运行 LicenseRecoverGUI.exe，进入批量页，选择应用父目录后只点击“扫描子目录”。
本次测试无需执行“一键恢复授权”或“方式三”等写入操作。

使用说明与历史变更：README.md / CHANGELOG.md。
