# LicenseRecover v1.2.0

This release consolidates the previous multi-path recovery workflow into a one-click recovery architecture with broader automatic detection across verified .NET and Java ITMC application generations.

## Highlights

- Adds unified application detection and one-click recovery coordination for supported Java and .NET applications.
- Keeps the existing native Windows x64 `LicenseRecoverGUI.exe` launcher, embedded Amazon Corretto 8 runtime, GitHub update button, and slim self-update flow.
- Local authorization objects continue to embed `RegeditInfo.UserID=fwq` while keeping outer `WebSerUserID` handling separate.
- Recovery keeps mandatory backups, post-write verification, and rollback-oriented safety checks.

## .NET compatibility

- Detects applications with `ITMC.Web.dll` plus either modern `ITMC.Regedit.dll` or legacy `itmcRegedit.dll`.
- Verified against sample families including:
  - YX030101 / `YX0301`
  - YX030204 / `YX0302`
  - YX030308 / `YX0303`
  - YX030322 / `YX0303`
  - DS01xx / `itmcIEC`
- Fixes detection for newer YX0303 deployments that contain only uppercase `ITMC.Regedit.dll`.
- Preserves product-specific local-license data and validates generated `regName` payloads with the verified DES/CBC implementation.

## Java compatibility

- Supports `ITMCReg.jar` and versioned `ITMCReg-*.jar` discovery, including nested `WEB-INF/WEB-INF/lib` layouts.
- Supports Virbox-protected authorization JARs through the existing recovery path before runtime use.
- Adds product/profile handling verified against:
  - XMT0107 -> `XMT01`, with product list read from `WEB-INF/classes/config.xml`
  - YT00129 -> `QT04`, with `QT0420` authorization product mapping
  - QT30103 -> `QT30103`, with product list read from `data/config.xml`
- Reads `global.system.VersionID` using both `key: value` and `key=value` configuration styles.
- Distinguishes applications that merely have `data/config.xml` from true QT30xxx-style applications whose data config contains `regInfo`.
- Adds `WEB-INF/classes/config.xml` fallback for XMT-generation product detection.
- Uses product-specific `regInfo` instead of a generic product list when the target application provides one.
- Writes and verifies webapp-root authorization configuration for generations whose `RegisterMain` runtime uses the application root path.

## Verification and regression coverage

CI now verifies, among other checks:

- Java 8 source compatibility.
- XMT0107, YT00129, and QT30103 profile mapping and configuration parsing.
- Modern uppercase-only .NET registration assembly detection.
- YX0303 and DS01xx product detection.
- Known-vector DES/CBC encryption and decryption.
- Generated local authorization JSON contains the expected `UserID`, `RegID`, and compatibility fields.
- Local XML updates preserve outer `WebSerUserID` while updating local authorization state.
- Backup, update ZIP safety, native Windows launcher packaging, portable archive, and slim update archive generation.

## Compatibility

- Java baseline remains Java 8.
- Windows 7 / Windows Server 2008 compatibility remains unchanged where supported by the target application/runtime.
- Portable builds include Amazon Corretto 8 for Windows x64.
- Existing legacy entry points remain available as compatibility fallbacks.
