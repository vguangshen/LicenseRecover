LicenseRecover v1.2.72
=====================

ITMC 离线授权恢复工具（Java / .NET），包含 Windows 便携启动程序。

启动：解压 LicenseRecover-latest.zip 后运行 LicenseRecoverGUI.exe。

v1.2.72 授权条件与代码证据识别更新
------------------
- 增加 YunClient 组合注册来源只读诊断，仅读取机器覆盖号和候选本地载荷，不读取 CRM 密码，不执行原生导入或写回。
- 独立审核 WMIC 覆盖号规则；只在可信命令环境与输出语义可核验时采用，失败仍待核。
- “本地记录标识未匹配”明确限定本次扫描环境；站点运行身份、缓存和其他来源仍需分别验证。
- 已审核入口通过恢复绿色，标签仍为“当前入口条件通过（来源未确认）”。“代码证据”列区分注册组件同原版、当前静态放行、替换候选及待核；绿色不自动表示确认 Patch。
- 成套代码指纹支持应用 classes/JAR/DLL 与固定绑定，按完整构建和 Patch 配方分组；多构建、缺件、混合集、别名及变动均保守处理。
- .NET 只读核对精确代码组合、当前机器、日期、无限计次和当前产品模式，不执行厂商程序集。
- Java 增加本地机器绑定、期限、无限计次及当前产品范围检查，精确绑定已审核代码与启动资源；不执行目标类。
- 授权状态和检测原因前移至应用列后，鼠标悬停可看完整原因。
- 当前本机 27 个副本验证 18 项入口通过；7 项无本地授权记录，1 项机器不符，1 项协议待支持。后 9 项仍有其他授权路径待核，不能断言整个软件未激活。
- 新增 YT00123 新安装未激活对照：当前实际本地记录缺失，保持其他授权方式待核；不因注册 JAR 相同或 Register.xml 存在认定通过。
- 状态列直接显示具体原因；完整入口拒绝显示“当前入口条件拒绝（原生状态待核）”，不冒认原生无效。
- 完整 Java 代码与依赖需要双重读取，单目录只读扫描时限调整为 30 秒；超时显示检测失败，不产生授权结论。
- 入口通过不区分原生激活与修改来源，不保证所有业务功能正常；真实原版/Patch 双指纹库仍为空。

本地测试：运行 LicenseRecoverGUI.exe，进入批量页，选择应用父目录后只点击“扫描子目录”。
本次测试无需执行“一键恢复授权”或“方式三”等写入操作。

使用说明与历史变更：README.md / CHANGELOG.md。
