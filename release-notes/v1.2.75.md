# LicenseRecover v1.2.75

本版新增 PT 系列 Java 软件（含 PT0405）的授权恢复兼容入口，复用已有 Java `RegisterMain` 流程。该版本适合在服务器副本上测试；静态识别和构建测试通过，不代表已经在真实 PT0405 网站上完成授权写回验证。

- **授权 ID：** 优先使用目标程序能确认的注册 ID；未识别到时，在明确执行恢复操作的情况下，可使用符合 `PT[0-9]{4,6}` 的软件目录名作为备用 ID。此备用 ID **不与** `SoftVersionID` 交叉校验。
- **继续使用原有 Java 流程：** 先确认实际 `RegisterMain` 启动构造器，再从目标注册组件获取 `RegStr`，按已有请求/本地写回路径执行，并在新 JVM 中复核。无法证明构造器或 `RegStr` 时停止，不修改授权文件。
- **PT 模块兼容：** 某些 PT 软件的 `RegStr` 是子模块列表，可能不包含整体 `SoftVersionID`。PT 使用目标注册组件实际返回的非空 `RegStr`，其他 Java 软件继续使用原有版本标识校验。
- **备份与恢复：** PT 备用入口强制备份现有授权文件；写入验证失败时尝试恢复原始文件。被动扫描不执行厂商注册类。
- **保护类加载：** 支持从工具运行目录读取 `virbox_keystream.bin` 作为可选本地密钥流。发行源码不因本次功能变更新增密钥材料。
- **测试：** 通过 Java 编译/测试、Windows 双注册组件与大写注册组件兼容性检查；新增目录名回退、不交叉校验、PT 模块列表以及缺少启动 ABI 时拒绝写入的回归测试。

## 在服务器上测试

1. 建议先备份 PT0405 网站目录及数据库，停止 Tomcat；优先使用完整副本或快照。
2. 更新工具至 v1.2.75。若工具未能读取保护类所需的密钥流，将 `virbox_keystream.bin` 放在工具 JAR/EXE 所在目录。
3. 先执行只读扫描，确认识别到了 PT 系列和备用注册 ID；再在副本中执行 Java 一键恢复。
4. 保留日志，检查 `JAVA_RUNTIME_ABI`、`PROBE`、`GENCODE`、`DOREG`、`VERIFY_FRESH` 等阶段及实际网站重启状态。不要只凭工具返回成功就认定网站全部功能可用。

**尚待实测：** PT0405 目标注册组件在服务器上能否读出可用 `RegStr`，以及 Tomcat 重启后是否接受本地授权。这次正式发布并不宣称已完成真实 PT0405 的授权验证。
