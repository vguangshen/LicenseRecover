# LicenseRecover v1.2.53

本版继续修复 DS2406 的本地授权生命周期识别和错误提示。

## 根因

完整 DS2406 部署包确认：干净安装时根目录可以只有 `systemConfig.yml`、`data/config.xml`、`WEB-INF` 等内容，而没有根 `config.xml`。

此前 v1.2.52 已经能够正确识别 `DS24` 父产品和当前 `DS2406` 子模式，但“未发现现有 RegStr”仍无法区分：
- 目标从未生成过本地授权配置；
- 已有配置存在，但 RegStr 不完整或不可读。

同时一键恢复的前置阻止消息没有阶段前缀，因此错误弹窗显示 `UNKNOWN`。

## 修复

- 对已确认的 DS24/DS2406 目标增加本地授权生命周期诊断：
  - `UNINITIALIZED_LOCAL_LICENSE`：目标根 `config.xml` 不存在；
  - `CONFIG_PRESENT_NO_REGSTR`：根 `config.xml` 存在，但目标 `getRegInfo()` 没有提供 RegStr；
  - `REGSTR_AVAILABLE`：已有本地授权能够提供 RegStr。
- 干净安装状态明确提示“未初始化本地授权”，不再把根 `config.xml` 缺失描述成异常路径。
- 配置存在但无 RegStr 时单独提示现有本地授权可能不完整或不可读。
- Java 计划前置阻止统一加 `[JAVA_PLAN]`，GUI 失败窗口现在显示 `JAVA_PLAN` 而不是 `UNKNOWN`。
- target-native probe 同步输出 `TARGET_BASE_CONFIG` 与 `TARGET_LOCAL_STATE`，方便真实机日志定位。

## 本地验证

使用完整 DS2406 目录进行 Java 8 兼容 lifecycle harness：
- `systemConfig.yml -> DS2406`：PASS
- `data/config.xml -> DS24`：PASS
- `<System id="DS2406">` 枚举：PASS
- 目标启动字节码证据：PASS
- 缺根 `config.xml` -> `UNINITIALIZED_LOCAL_LICENSE`：PASS
- 根配置存在但无 RegStr -> `CONFIG_PRESENT_NO_REGSTR`：PASS
- 非空 RegStr -> `REGSTR_AVAILABLE`：PASS
- `[JAVA_PLAN]` 错误分类：PASS

本版仍保持 fail-closed：生命周期诊断只解释目标当前状态，不会把 DS2406 模式 ID 当作新的授权 RegStr。
