# LicenseRecover v1.2.22

本版根据真实 DS50109 与 DS50113 目标目录进一步收紧 Java DS501/classes-config 的 RegStr 证据链，减少不必要的目标 `RegisterMain.getRegInfo()` 动态读取。

- **DS501 主 RegStr 可纯静态确认**：只有目标目录同时证明 `systemConfig.yml VersionID = classes/config.xml SoftVersionID`、`SystemInfo` 从 `config.xml/SystemSoft` 写入 `registerId`、`RegisterContant` 从 `global.system.VersionID` 写入/持有 `versionID`，并且 `RegisterListener` 使用 `RegisterMain(registerId).getRegInfo().getRegStr().contains(versionID)` 时，才把当前具体 VersionID 作为主 RegStr。
- **真实样本结果**：DS50109 现在可静态得到 `AuthorizationFamily=DS501 / RuntimeProductID=DS50109 / RegStr=DS50109`；DS50113 同理得到 `DS501 / DS50113 / DS50113`。
- **兼容授权不覆盖主身份**：DS50113 中的 `QT1001 / QT100112` 等替代平台检查仍只视为兼容链，不会覆盖当前 DS50113 的主 RegStr。
- **Fail-closed 保持**：缺少 `systemConfig.yml`、RegisterContant VersionID 来源证明、RegisterListener membership 检查或任一关键目标证据时，不会从 `DS501xx` 命名规则猜 RegStr；若运行 ProductID 已有充分证据且目标 ITMCReg 可用，则仍保留“目标组件动态读取”，否则阻止自动恢复。
- **减少动态加载**：静态证据完整的 DS501 应用在批量扫描阶段不再为了 RegStr 调用目标注册组件，扫描更快，也进一步减少执行厂商注册代码的次数。
- **PRE-BLOCK FIRST 不变**：v1.2.21 的 Java/.NET 首次 Patch 前授权网络隔离仍完整保留。
