# LicenseRecover v1.2.42

## 批量备份清理

- 在“批量应用”页新增“批量清理备份”维护功能，直接复用当前父目录作为扫描范围。
- 默认按“每个原文件”保留最近 3 份备份，可在 0–50 之间调整；不同备份代际会按同一个原文件合并排序，避免历史尝试长期堆积。
- 删除前先扫描并展示受管理备份数量、保留数量、拟删除数量与预计释放空间，必须再次确认后才会执行。
- 仅识别 LicenseRecover 自身的 `prewrite`、`prepatch`、`preoneclick` 以及已知旧版时间戳备份命名，不会把普通 `.bak` 当作清理对象。
- 扫描和删除均拒绝符号链接；执行删除前再次确认文件仍位于所选根目录内、仍为普通文件且名称仍符合受管理备份规则。
- 批量扫描/执行任务运行期间禁止启动备份清理，避免维护操作与正在进行的批处理互相干扰。

## Verification

- 新增独立 backup-cleanup CI self-test，覆盖多代备份命名识别、按原文件保留最近 N 份、实际删除、普通 `.bak` 排除与无关时间戳备份排除。
- 正常 `Verify source`、Java 8 编译/回归、Windows/.NET 集成、便携包构建和原生启动器打包仍作为正式发布门禁。

本版本仅增加备份文件维护能力，不改变 v1.2.41 的应用处理/验证逻辑。
