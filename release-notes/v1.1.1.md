# LicenseRecover v1.1.1

This maintenance release restores the embedded Java runtime in the portable distribution and reduces the size of future self-updates.

## Highlights

- `LicenseRecover-latest.zip` once again includes an embedded Windows x64 Java runtime, so users do not need to install Java separately.
- The embedded runtime is Amazon Corretto 8.492.09.2 / OpenJDK Runtime 1.8.0_492-b09, matching the runtime family recovered from the pre-refactor portable package.
- The JRE keeps its `LICENSE`, `ASSEMBLY_EXCEPTION` and `THIRD_PARTY_README` files, plus a source/licensing notice.
- A separate `LicenseRecover-update.zip` contains application files only and intentionally excludes `jre/`.
- The built-in updater in v1.1.1 prefers the smaller update ZIP when available, preserving the installed embedded JRE.
- For compatibility with v1.1.0 and older updater behavior, the full portable ZIP remains available and can still be installed as an update fallback.
- CI verifies both ZIP files and writes both hashes to `SHA256SUMS.txt`.

## Runtime support asset

The pinned embedded runtime is maintained as the prerelease/support asset:

`runtime-corretto8-8.492.09.2-win-x64`

Keeping the JRE as a Release asset avoids adding more than 100 MB of runtime files back into the Git source tree while preserving a reproducible portable build.

## Assets

- `LicenseRecover-latest.zip` — portable package with embedded JRE
- `LicenseRecover-update.zip` — slim self-update package
- `SHA256SUMS.txt`
