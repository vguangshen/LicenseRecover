# LicenseRecover v1.2.20

本版纠正 v1.2.19 对真实 `YX0102` .NET 样本注册身份的误判。修复继续遵循“目标目录自证、无法确认即阻止”，不新增任何固定 ProductID / ProName / RegStr / RegisterVersion.db 密钥兜底。

- **YX0102 / .NET 原生注册身份纠正**：真实目标 `Web.config` 的 `productName=YS01` 才是本地注册页直接传给 `RegeditMain` 的 ProName；`config.xml` 的当前 `SoftVersionID=YX0102` 是该直接注册链使用的 RegStr。现在检测结果按目标目录和目标 `ITMC.Web.dll` 的 `RegeditNew / NewRegistry / DoRegistry / GetProVersion / CheckSoftVersionID` 证据联合确认，执行身份为 `ProName=YS01`、`RegStr=YX0102`，不再把目录版本号 `YX0102` 误当成 ProName。
- **RegisterVersion.db 只读兼容关系解析**：新增目标版本库关系解析器。3DES 密钥不写死在 LicenseRecover 中，而是从当前目标 `ITMC.Web.dll` 的 24-byte 字符串候选中提取，并且只有“恰好一个候选”能将数据库关系解密为当前 `SoftVersionID` 与合法父产品/父版本时才接受。真实样本可由此读出旧授权兼容关系，但这些关系只用于兼容证据和诊断，不覆盖原生注册页的直接 ProName/RegStr。
- **Fail-closed 回归**：`Web.config` 的 ProName 若不能由目标 DLL 同一身份与注册流程证明，则拒绝；RegisterVersion.db 缺失、目标 DLL 不含正确密钥、数据库内容损坏或出现多密钥歧义时，不猜测兼容关系。
- **原生闭环保持不变**：.NET 一键恢复仍执行 `gencode -> RegeditMain.DoRegistry -> RegeditMain.CheckReInfo`；只有原生校验通过后才阻断联网，失败时恢复注册配置快照。
- **YX030506 / Java 保持 v1.2.19 的正确实现**：继续要求目标 `IXmlUtil.class + ProjectApplicationRunner.class` 完整证明 `SoftVersionID -> PRODUCT_ALL_NUM -> RegisterMain.checkReInfo()`，解析结果仍为授权族 `YX0305`、运行 ID `YX030506`、RegStr `QT100101,QT100102`。

> v1.2.19 已发布且其中关于 YX0102 `ProName=YX0102` 的说明不准确；请以 v1.2.20 及之后版本为准。
