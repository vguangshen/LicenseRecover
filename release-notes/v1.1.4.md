# LicenseRecover v1.1.4

This release adds a real Windows native GUI launcher so users can double-click an EXE and still get the current overlay UI, version display, and GitHub update button.

## Highlights

- Adds a new native Windows x64 `LicenseRecoverGUI.exe` launcher built from source with MinGW-w64.
- Double-clicking `LicenseRecoverGUI.exe` now launches the same `LicenseRecoverModernGUILauncherUiPatch` entry point used by `run_gui.bat`.
- The native launcher prefers the bundled `jre\bin\javaw.exe`, then falls back to other available Java runtimes, and forwards command-line arguments to the Java launcher.
- The native launcher validates that `LicenseRecoverOverlay.jar` and `LicenseRecoverGUI.jar` are present before starting.
- The existing old executable remains in the package as `LicenseRecoverGUI-legacy.exe` for compatibility.
- CI cross-compiles and validates the EXE as a Windows x64 GUI PE binary, checks its embedded runtime references, injects it into both portable and slim update ZIPs, and regenerates SHA-256 hashes.

## User entry points

- `LicenseRecoverGUI.exe` — recommended Windows GUI entry point.
- `run_gui.bat` — script fallback; launches the same modern UI/update path.
- `run_gui_legacy.bat` — original full-featured GUI with the overlay layout/update patch.
- `LicenseRecoverGUI-legacy.exe` — unmodified old executable retained only as a compatibility fallback.

## Compatibility

- Java 8 remains the Java compatibility baseline.
- Windows 7 / Windows Server 2008 compatibility remains unchanged.
- Portable builds still include Amazon Corretto 8 for Windows x64.
- v1.1.3 local authorization behavior (`RegeditInfo.UserID=fwq`) is unchanged.

## Assets

- `LicenseRecover-latest.zip` — portable package with embedded JRE and native EXE launcher
- `LicenseRecover-update.zip` — slim self-update package with native EXE launcher
- `SHA256SUMS.txt`
