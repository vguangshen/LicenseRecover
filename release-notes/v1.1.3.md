# LicenseRecover v1.1.3

This release fixes the Java way-1 local authorization identity and closes a source/runtime packaging gap discovered during authorization analysis.

## Highlights

- Java way-1 local authorization now writes `RegeditInfo.UserID=fwq` before the authorization object is serialized and encrypted into `regName`.
- `WebSerUserID` remains a separate compatibility/configuration field; the runtime authorization identity is carried inside `regName`.
- The build now recompiles `LicenseRecover.class` and updates the distributed `LicenseRecover.jar`, so source behavior and Release behavior stay aligned.
- The dry-run and self-check logs expose the effective local authorization UserID for easier diagnosis.
- Smoke tests verify that applying the local-authorization identity sets `UserID` to `fwq`.
- The build additionally checks the final `LicenseRecover.jar` bytecode with `javap` for the `RegeditInfo.setUserID` call and the `fwq` string constant.

## Compatibility

- Java 8 compatibility remains the baseline.
- Windows 7 / Windows Server 2008 compatibility remains unchanged.
- Embedded Amazon Corretto 8 is still included in the portable package.
- The GitHub updater, slim update package, GUI layout fixes, and bottom-right update button are unchanged.
