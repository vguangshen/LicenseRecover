# LicenseRecover v1.2.58 — Diagnostic reliability

This maintenance release addresses unresponsive verification status and timeout diagnostics. **It does not implement or claim working one-click DS01xx authorization bypass/write-back.**

## Fixes
- DS0101/DS01xx legacy .NET applications display an immediate, explicit unsupported write-back message rather than leaving the one-click control in an indefinite "executing and verifying" state.
- Legacy detection identifies DS01xx from its configuration before running expensive modern-assembly product inspection on the Swing UI thread.
- Native helper calls now have a 180-second deadline, concurrent output reading, termination on timeout and a structured [NATIVE_TIMEOUT] result.
- Added deterministic Java 8 smoke tests for unresponsive native helper processes and fail-closed DS01xx UI preflight.

## Tested
- Local read-only inspection of DS0101.zip confirmed SoftVersionID DS0101 and both ITMC.Regedit.dll and itmcRegedit.dll.
- Java 8 source smoke tests, synthetic timeout scenario and existing Windows .NET integration checks must pass before publishing.

## Limitations
- This update is not a new Patch engine and does not circumvent license checks.
- Native IIS startup, vendor registration, and real DS0101 authorization restoration have **not** been verified in this environment.
- Only use the original application's licensed registration workflow for DS01xx. Existing explicit advanced operations are unchanged.
