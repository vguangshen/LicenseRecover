# LicenseRecover v1.1.2

This maintenance release fixes long authorization-code layout overflow and makes software update access visible inside the GUI.

## Highlights

- Long registration request / offline authorization code values no longer widen the whole single-application panel.
- Overflowing hexadecimal content stays clipped / horizontally scrollable inside its text field instead of pushing action buttons off-screen.
- The original full-featured GUI receives the same layout constraint through the compatibility launcher.
- A visible `检查更新` button is now placed at the bottom-right of the GUI, together with the current version number.
- Both the modern launcher and the legacy GUI script route through the visible update-control layer.
- The existing GitHub stable-release updater, SHA-256 verification, embedded JRE portable package and slim self-update package are unchanged.

## Compatibility

- Java 8 compatibility remains the baseline.
- Embedded Amazon Corretto 8 portable runtime remains included in `LicenseRecover-latest.zip`.
- Recovery protocols and Java/.NET authorization logic are unchanged.

## Assets

- `LicenseRecover-latest.zip` — portable package with embedded JRE
- `LicenseRecover-update.zip` — slim self-update package
- `SHA256SUMS.txt`
