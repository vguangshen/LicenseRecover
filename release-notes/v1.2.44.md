# LicenseRecover v1.2.44

## YX030506 / ProjectSourcesPath 修复

- 修复 YX030506 一类 Spring Java 应用的运行路径识别：目标 `ProjectApplicationRunner` 使用 `ProjectSourcesPath.projectPath("/")` 将 `WEB-INF/classes` 作为三参数 `RegisterMain` 的配置基目录，而不是 `ServletContext.getRealPath("/")` 的 WebApp 根目录。
- runtime profile 只有在目标 `ProjectSourcesPath.class` 同时证明 `classpath:`、`ResourceUtils.getURL()`、`URL.getPath()`、`File.getAbsolutePath()` 链时，才接受该 classpath-root 路径；否则仍保持 fail-closed。
- YX030506 的 native 写回因此落到目标实际消费的 `WEB-INF/classes/config.xml`，并继续要求 fresh JVM `checkReInfo()` + `getRegInfo().RegStr` 全部通过后才显示 OK。
- 批量扫描中的配置目标展示同步改为 `WEB-INF/classes/config.xml`，避免把此代产品误显示为 lib/root 配置。

## Verification

- 新增 YX030506 classpath-root 显式路径选择回归。
