# LicenseRecover v1.2.70

增加真正的本地授权条件检查，并把无法确认的原因直接显示在状态列。

- Java 新增九个 J1 本地优先应用及 XMT 多产品模式入口的独立只读检查：完整代码/依赖与启动资源匹配后，核对当前机器绑定、期限、无限计次和实际产品范围。没有运行目标类、写回授权或消耗次数。
- 剩余应用细分“无本地授权”“本地机器不符”“验证协议待支持”等原因；保留网络/HASP 等尚未闭合的范围，不把局部失败直接说成整个软件未激活。
- 增加“授权入口明确拒绝（未激活）”：仅用于完整当前入口及其无接受后备分支均已审核的明确拒绝，不冒充厂商原生验证。
- 状态和证据在应用列后显示，完整原因自动换行。完整代码双重哈希的每目录预算调整为 30 秒，超时显示检测失败，不产生授权结论。
- 补入新安装 YT00123 的精确构建与资源指纹，修正同一入口类属于多个完整构建时只检查第一项的问题；无适用规则时保留各策略的具体原因。新样本未被误判为已激活或可信 Patch。

本机 26 个独立扫描输入副本：18 个当前授权入口通过（独立蓝色），6 个当前入口无本地授权记录，1 个本地机器绑定不符，1 个协议待支持。后 8 项仍不能断言整体未激活；当前样本没有证明整个入口明确拒绝的实例。不同机器或文件变化会重新计算结果。

蓝色不区分厂商激活与修改来源，也不保证全部业务功能正常。可信原版/Patch 双指纹库仍为空。未提交真实注册码、机器标识、敏感配置或厂商二进制。

请解压完整包后运行 LicenseRecoverGUI.exe，选择父目录并点击“扫描子目录”。已有版本可通过“检查更新”安装轻量包。两份 ZIP 均须通过 SHA256SUMS.txt 校验。

逐项证据和限制见 docs/REAL_SAMPLE_DIAGNOSTICS_20261102.md，以及 Java/.NET 对应审核文档。
