# LicenseRecover v1.2.76

## 只读扫描与识别改进

- Java 应用未确认内部运行 ID 时，单个及批量扫描显示应用安装根目录名作为未验证候选，日志明确标明其来源。
- 优先显示已确认的内部 ID；目录名不会替代执行 ID、授权证据或改变 Patch 规则。
- 修复目标文件缺失、扫描期间变化或检查不完整时可能被后续判定覆盖的问题，保持未验证状态。
- 新增只读识别和证据稳定性回归测试。

- 按 QT100101 样本的标准目录布局增加合成回归测试，覆盖根目录、WEB-INF、classes 和 lib 的选择方式，以及 XML 代号回退；忽略名称类似 JAR 的目录。

- Java 方式三 CLI 现在根据与 QT100 只读扫描一致的根目录解析规则定位目标；支持从应用根、WEB-INF、classes 和 lib 选择路径。
- 修复 --remove-net --dry-run 被当作真实写入执行的风险，改为只读扫描；命令行写入现在要求通过独立 prepatch 备份检查。
- JAR 识别要求存在 RegisterMain.class，受保护的类明确标记为兼容性待核，不根据目录名宣称 Patch 成功。

本版本不绕过受保护类的兼容性验证，也不放宽授权证据要求。实际发行包须通过本版本源码和 Windows 兼容性检查后发布。
