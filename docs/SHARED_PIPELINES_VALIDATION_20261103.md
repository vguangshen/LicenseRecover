## 后续证据需求

同系列后续版本继续复用公共谓词和启动布局，不为每个名称复制算法。新组件的接口形态只用于同族候选识别；必须审核实际入口、依赖、初始化和后备路径，再登记相应证据绑定。方法名或注册 JAR 相同不足以对未知网站构建升绿。

待核部分仍需只读审计小写 VM 分支、组合产品关系与真实站点采用来源、网络/HASP 及运行缓存语义。原版/Patch 判断还需要来源可核验的同版文件对；已安装文件、备份名或历史日志不能补足。YT00123 的未改动来源由用户确认，本地无记录也不等于所有授权路径均拒绝。
