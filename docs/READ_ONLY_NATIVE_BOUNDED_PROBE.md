用户在静态审计后明确批准可以直接调用原生方法。本次只对 **DS2406 / J2** 的私有独立副本进行调用对照，未执行注册、恢复、Patch、联网验证或硬件狗操作。生产扫描器没有接入此实验宿主，原生授权结果仍为未验证。

## 运行边界

独立 Java 8 子进程在加载厂商类之前安装不可替换的 `SecurityManager`。允许读取实验副本和该 JVM 的 Java home；拒绝文件写入、删除、执行、原目录及其他路径读取、Socket/connect/listen/accept、子进程、native library 加载、反射提升、线程修改、安全管理器替换及未列入允许范围的其他权限。厂商 stdout/stderr 被丢弃，宿主仅输出阶段、返回类型、异常类型及拒绝类别，不输出配置值、密钥或机器标识。

九项权限拒绝自检在加载厂商类之前通过，包括原目录普通路径及 Java 8 URLClassLoader 所用的前导反斜杠路径拼写。该 Java 8 构建对本地 JAR 的权限检查会使用 `\D:\...` 的路径拼写；包装器仅规范化这种绝对盘符拼写，然后检查它仍位于允许根目录内。

进程设置 256 MB 堆上限和 20 秒外部超时。超时仅终止本次新建的子进程。没有通过替换返回值、反射修改字段或放开副作用来取得结果。

## 可得结论与限制

本次确实调用了副本中的构造器和 `checkReInfo`，但没有获得原生布尔判定。验证链因安全限制中断，异常可能改变厂商的后续控制流，**不能解释成授权无效，更不能解释成验证成功**。没有为了继续执行而放开反射、文件写入、真实目录读取、进程、native 或 Socket 权限。

实验动态阻断点位于依赖初始化，尚未动态到达静态审计已经发现的注册计次写回分支。不能声称本次动态实验证明了该写入已发生，也不能因其尚未发生而推翻静态证据。

这是进程内权限限制的可复现对照，不是操作系统沙箱、完整 JVM 安全证明或厂商验证器的生产只读验收。没有将其升级为原生有效/无效检测器；三个组件族的静态副作用拒绝结论及原版/Patch 样本缺口保持成立。若继续研究完整离线判定，应独立实现并审核机器绑定、解密、时限、计次、产品模式及网络/HASP 后备语义，而不能把放宽实验限制后的调用结果当作只读证明。
