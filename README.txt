LicenseRecover v1.2.58
=====================

ITMC 离线授权恢复工具（Java / .NET），包含 Windows 便携启动程序。

启动：解压 LicenseRecover-latest.zip 后运行 LicenseRecoverGUI.exe。

v1.2.58 可靠性更新
------------------
- DS01xx 目标在点击一键恢复时会立即显示当前支持状态，不再误报“正在校验”。
- DS01xx 检测不再无谓地解析现代 .NET 注册组件。
- 对原生辅助程序增加超时和诊断日志，避免无限等待。
- 本版本不提供绕过许可校验的自动写回功能；DS01xx 合法注册请使用应用原有流程。

使用说明与历史变更：README.md / CHANGELOG.md。
