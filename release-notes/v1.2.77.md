## QT100 系列一键恢复适配

- 修复 QT1001xx 同模板应用（例如 QT100111）被一键恢复计划过早判定为“注册 ID 仅能由旧兼容规则推测”的问题。应用的 YAML、classes/config.xml、模块列表及注册启动类必须互相吻合，才会确认具体运行注册 ID。

- 缺失关键配置/启动类、YAML 与 XML 代号不一致时仍拒绝进入授权写入。
