# LicenseRecover v1.2.6

本版本根据实际 GM00401 ASP.NET 安装样本补齐 GM004 家族识别。

## GM00401 样本结论

- 根目录 config.xml 明确 SoftVersionID=GM00401，且没有 regInfo。
- ITMC.Web.dll 同时包含 GM00401 与 GM004；GM004 位于 SystemSoft、SoftVersionID、WebSerSoftNo、regName、regType 等注册配置字符串附近。
- 因此确认授权产品族 / ProName 为 GM004。
- DLL 当前只发现同族具体项 GM00401，因此 RegStr 为 GM00401。
- Web.config 中 productName=YX0301 与实际 GM00401 身份冲突，按历史遗留业务配置处理，不参与授权产品识别。

## 安全规则

只有目标程序集同时提供具体 GM00401 和家族 GM004 证据时才接受映射；否则保持产品号未确认并拒绝 .NET 一键写回。
