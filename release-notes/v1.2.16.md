# LicenseRecover v1.2.16

本版优化批量应用扫描体验，解决扫描 Java class/JAR、.NET DLL 元数据或动态 RegStr 证据时窗口短暂无响应、用户容易误以为软件卡死的问题。

- 批量“扫描子目录”从 Swing EDT 主线程移到 `SwingWorker` 后台线程，目录分析期间窗口仍可正常拖动、切换与刷新。
- 进度条改为实时显示：总目录数、已完成数、百分比、当前正在扫描的目录，以及识别 / 未识别 / 异常累计数量。
- 每个目录开始分析前就更新“正在扫描”状态，因此即使某个 JAR/DLL 的证据分析耗时较长，也能明确看到软件正在处理哪个项目。
- 扫描结果逐项增量加入表格，不再等全部目录完成后才给用户反馈。
- “取消”按钮现在同时支持取消正在进行的扫描任务；取消后保留已经扫描完成的结果并显示完成数量。
- 若用户在尚未扫描时直接点击“批量执行”，会先后台扫描，扫描成功后自动继续原来的批量执行流程，不改变既有使用习惯。
- 批量执行开始时重新初始化进度条，避免扫描完成的 100% 状态与后续执行进度混在一起。

> 本版只调整任务调度与 UI 反馈，不改变 v1.2.15 的 Java/.NET 目录证据识别、fail-closed 和原生注册闭环规则。
