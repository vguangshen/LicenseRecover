# LicenseRecover v1.2.55

本版为 DS2406 request-only 本地注册增加第二阶段：**导入用户已有的合法注册码，并由目标组件自身写入和验证。**

## Two-stage flow

1. 工具调用目标 `RegisterMain.newRegistry()` 生成本机申请号。
2. 用户通过已有合法授权渠道取得对应注册码。
3. 用户把注册码粘贴到主界面。
4. 工具调用目标：
   ```java
   RegisterMain.doRegistry(requestCode, authorizationCode)
   ```
5. 新 JVM 重新加载目标注册组件，执行目标启动构造器 + `checkReInfo()` + `getRegInfo()`。
6. 读取持久化 RegStr，并要求包含当前 `DS2406`；否则判定失败并回滚。

## Important boundaries

- 本流程不会为用户生成注册码。
- “已有注册码”只来自用户输入。
- request-only 阶段仍然零写入。
- 只有用户明确点击“导入已有注册码并验证”后才调用目标 `doRegistry()`。
- 失败时自动恢复 Java 授权相关文件到导入前快照；导入前不存在的 `config.xml` 会被删除。
