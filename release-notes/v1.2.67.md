# LicenseRecover v1.2.67

## 修复 v1.2.66 批量扫描全部红色“检测异常”的问题

- 修复正式打包遗漏扫描器内部类的错误。v1.2.66 批量扫描日志出现 `NoClassDefFoundError: LicenseRecoverReadOnlyPatchScanner$Runtime`，导致所有识别目标都变成红色“检测异常”。**这是程序运行时缺少 Java 类，并不说明被检测应用授权无效或文件损坏。**
- `LicenseRecoverRuntime.jar` 和 `LicenseRecoverOverlay.jar` 现在打包 `LicenseRecoverReadOnlyPatchScanner`、`LicenseRecoverReadOnlyFingerprint` 及必要的嵌套枚举/数据类。
- CI 不仅检查编译目录中的源码，还使用“正式发行 JAR 优先于旧 GUI JAR”的真实启动类路径，实际调用 Java/.NET 只读扫描器；缺少类、加载位置不正确、误判绿色均会导致 CI 失败。
- 在完整便携版和轻量更新包**最终 ZIP 解压后**分别执行相同的运行期检测，防止构建成功却无法在用户安装包中加载。
- 保留 v1.2.66 的只读扫描、五色显示、多文件证据一致性及误判防护，不修改既有授权写回算法。

## 授权检测边界不变

- 当前经过独立审核的**真实原版/Patch 指纹库仍为空**，Java/.NET 原生授权校验器尚未完成完整的无副作用审计。修复后大多数真实应用预计显示**灰色「未验证」**，而不是深绿或浅绿；这不能证明软件未激活或 Patch 无效。
- 只有实际只读指纹扫描失败才显示红色；不依赖历史 Patch、配置、备份、联网记录猜测授权。
- 请优先用应用目录副本验证“扫描子目录”，不要为测试状态色而执行授权写入操作。

## 自动更新

- 已安装的旧版本在软件右下角点击 **「检查更新」**，通过 GitHub 最新正式 Release 下载 `LicenseRecover-update.zip`，与 `SHA256SUMS.txt` 对照后安装。
- 也可以下载 `LicenseRecover-latest.zip`（Windows 便携版，带 JRE）。
- 修复关联 PR：https://github.com/vguangshen/LicenseRecover/pull/54
