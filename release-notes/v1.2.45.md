# LicenseRecover v1.2.45

修复 v1.2.44 中 DS50109 与 YX030506 批量扫描重新落入“待确认”的回归。

- 根因：后续 fail-closed 加固要求目标二进制出现独立 DS501 / YX0305 ASCII token，而真实样本主要保存具体 mode 与同族 System 列表。
- 修复：classes/config.xml 必须明确给出当前 SoftVersionID，并同时枚举当前 System id 和至少一个同族 sibling id，才确认 local authorization family。
- DS501/YX0305 family 不能直接充当 runtime ProductID；具体 DS50109 / YX030506 仍由目标注册/启动数据流证明。
- DS50109 的 RegStr 仍需 SystemInfo/RegisterContant/RegisterListener 链证明。
- YX030506 仍需 IXmlUtil -> PRODUCT_ALL_NUM -> ProjectApplicationRunner -> RegisterMain 链证明，且继续使用 WEB-INF/classes ProjectSourcesPath 配置基目录和 fresh-JVM 校验。
- 回归夹具改为真实 classes/config 的同族 System 枚举，避免人工 family token 再次掩盖该问题。
