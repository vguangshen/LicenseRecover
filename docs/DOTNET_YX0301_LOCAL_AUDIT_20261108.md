## 已核对的入口与初始化

`PubBase.CheckReg_` (`0600024F`) 在大写检查成功后复制日期、机器和产品范围等属性；只有大写失败才转入小写兼容检查。小写 `RegeditInfo` 的 `0600006A..06000081` 是直接字段 getter/setter；其构造器 `06000082` 经静态 FOAP 恢复后为 25 条指令、80 字节 CIL，只设置默认字段并调用 `DateTime` / `Object` 方法，没有在该方法体中调用 VM 分派、注册、文件或网络操作。此结论限定于已恢复的方法体，不替代整个模块保护初始化的证明。

该 Web 版本还在检查成功后扩展 YX030101 / YX030102 的模式别名。共享谓词继续要求载荷直接覆盖当前模式，不用别名扩展放宽绿色条件。

启动方法 `Global.Application_Start` (`06000162`) 调用 `CheckReg(true)`；登录页 (`06000175`) 仅在其返回“需要注册”时跳转注册页。它们确认了真实门槛入口，但不足以单独证明整个网站接受。

## 完整网站入口尚缺的证明

`CheckReg` (`0600024D`) 在当前产品检查前调用 `GetCurrRegVersionSettingDic` (`0600024E`)。后者读取当前模式的父产品关系；`DBPathHelper` 初始化器 `06000E8C` 明确构造站点根目录下的 `Data/db/RegisterVersion.db` 路径。文件存在时，进入 LiteDB 查询、关系解密及父产品模式选择。

这条路径的查询方法 `DbHelperNDB.Query` (`060001D0`) 只有清理用的 `finally`，没有把所有失败转换为空结果的 `catch`。当前只读扫描尚未纳入该数据库、查询与解密结果，也没有闭合所有先行父产品分支。不能把独立副本中未复制该数据库误认作真实站点不存在，更不能只凭小写构造器可读就升级为完整入口通过。

因此本构建仅允许绑定 **MODERN_LOCAL_DIAGNOSTIC**，`positiveEntryAudited=false`。即使现代本地核心条件满足，也只报告 `LocalCondition.SATISFIED / Acceptance.UNVERIFIED`，保持灰色。

## 当前样本观察

当前 YX030118 的独立只读 WMI / WMIC 身份读取完成；用固定产品 YX0301 调用共享本地谓词，得到 `Acceptance.UNVERIFIED / LocalCondition.UNSUPPORTED`。当前注册分派为 `regType=3`，并非本地优先接受分支；没有执行它可能先调用的联网路径。该观察不表示未激活、原生拒绝或确认 Patch。
