# LicenseRecover v1.2.66

## 本次升级：只读授权状态识别（正式版）

- 批量扫描状态显示分为五类：**深绿色=经独立原生校验确认授权有效；浅绿色=经可信原版/Patch 指纹确认已修改；白色=原生校验明确无效；灰色=证据不足、未验证；红色=检测失败**。
- 扫描基于当前磁盘上的 Java/.NET 应用文件，不从曾执行成功的 Patch、备份、历史记录、配置文件或联网标记推定当前授权有效。
- 只读扫描器加入经审核版本号、相对路径、SHA-256 双指纹校验。拒绝路径遍历、符号链接/硬链接重复证据、Windows 盘符相对路径和备用数据流。
- 多个审核文件必须全套一致；混合原版与 Patch、文件缺失、数据异常或前后两轮 SHA-256 结果不一致，均不允许确认整套 Patch。
- 增加异常统计、检测详情与回归测试；不改变现有一键恢复或方式三的写入行为。

## 当前功能边界（务必阅读）

**本正式版包含已自动化验证的状态显示及防误判逻辑，但真实授权状态自动确认尚未完成。**

- 生产可信原版/Patch 指纹库**仍为空**，尚未取得独立审核的真实软件原版和 Patch 对照文件。因此现阶段真实 Java/.NET 应用通常显示**灰色“未验证”**，不能根据没有绿色判断软件未激活或 Patch 无效。
- 目标软件原生授权验证接口尚未通过完整无副作用审计，暂不接入批量状态扫描。不能把有 RegStr、配置、历史成功操作或存在原生验证方法当作“原生有效”。
- 灰色不代表未激活，浅绿色即使在日后出现也只证明代码精确匹配可信 Patch，并**不**等于原生许可证校验通过。
- 建议首次测试先对应用目录副本执行**扫描**，不要为观察颜色而执行写入操作。

## 发行与更新

- 旧版点击软件右下角 **“检查更新”**，可通过 GitHub 最新正式 Release 识别并升级至 **v1.2.66**。
- 常规下载：`LicenseRecover-latest.zip`（完整便携包，带 Windows x64 内置 JRE）。
- 软件自动更新：优先下载并校验 `LicenseRecover-update.zip`；随包提供 `SHA256SUMS.txt`。
- 发行前源代码验证和两项 Windows 集成测试必须全部通过；打包文件 SHA-256 必须与 CI 产物对应。
- 本版从 PR #54 所在开发分支构建正式版本，PR 仍保持开放，不等于 PR 已合并到 main。
